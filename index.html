Prompt Style Guide

Prompt Weight System

Use the weight controls next to each input field to adjust the importance of each prompt section. Higher values give that section more emphasis in the final image.

  • 1.0: Default weight (normal emphasis)
  • Above 1.0: Increased emphasis (e.g., 1.5 = 50% more important)
  • Below 1.0: Reduced emphasis (e.g., 0.5 = 50% less important)

Creating Effective Prompts

  • Be specific and descriptive in each section
  • Use clear, detailed adjectives
  • Include specific technical terms for better results
  • Balance positive prompts with thorough negative prompts
  • Experiment with different weight values

Sharing & Saving

You can save prompts locally or share them with others:

  • The "Save Prompt" button stores the prompt in your browser
  • The "Share Prompt" button creates a link that contains all settings
  • Saved prompts will appear at the bottom of the page

Keyboard Shortcuts

Use these keyboard shortcuts for faster workflow:

  • Ctrl+Space - Generate random prompt
  • Ctrl+S - Save current prompt
  • Ctrl+P - Copy positive prompt
  • Ctrl+N - Copy negative prompt
  • Ctrl+F - Copy full prompt
  • Ctrl+Delete - Clear all fields
  • Escape - Close this guide
